# Registro de Asistencia — Instructores

Sistema web para registrar ingreso y salida de instructores mediante códigos QR.

## Estructura

- `index.html` — estructura de la página.
- `css/style.css` — todos los estilos.
- `js/app.js` — toda la lógica JavaScript.
- Las librerías `jsQR` y `QRCode.js` se cargan desde CDN.

## Para GitHub Pages

El archivo `index.html` debe permanecer en la raíz del repositorio.

Configuración recomendada:
- Branch: `main`
- Folder: `/ (root)`
