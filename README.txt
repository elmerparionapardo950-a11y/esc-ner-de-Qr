# Asistencia QR - estructura organizada

Archivos:
- index.html  -> estructura y contenido de la página
- style.css   -> todos los estilos
- script.js   -> toda la lógica JavaScript

Para ejecutar:
1. Mantén los 3 archivos en la misma carpeta.
2. Abre index.html en el navegador.
3. Para usar la cámara QR, el navegador puede requerir HTTPS o localhost.
